# movie-recommender
A smart and user-friendly movie recommendation system that helps users discover movies based on their interests, ratings, genres. This project uses recommendation algorithms to provide personalized movie suggestions and improve the movie discovery experience.<br><br>
LINK: https://movie-recommender-lgw5p4cy9uxusnyeega9cf.streamlit.app/<br>
*Features<br><br>
  Recommend movies based on user preferences<br>
  Search movies by title <br>
  Personalized recommendation engine<br>
  Display movie posters, and descriptions<br>
  Responsive and clean user interface<br>
  Fast and efficient recommendation processing<br>
*Technologies Used<br>
  Python and JavaScript (depending on your stack)<br>
  Machine Learning and Recommendation Algorithms<br>
  Pandas, NumPy, Scikit-learn<br>
  Movie dataset (TMDB)<br>
